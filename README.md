# Banner Design Notes — Hemangi Mahajan GitHub Profile

Reference documentation for the header/footer banner assets used in `README.md`.
Files: `hemangi-mahajan-github-banner.svg` (header) · `hemangi-mahajan-github-footer.svg` (footer)

---

## Overall Style
- Luxury technology, minimalistic, modern, sophisticated
- Premium 3D look with cinematic lighting
- Clean, uncluttered composition
- Professional portfolio aesthetic — not a generic coding banner

## Main Focus (Header)
- **"HEMANGI MAHAJAN"** placed center-left in bold, elegant, modern typography
- Subtitle beneath the name: *Final Year IT Student | Software Development | Cloud & DevOps*
- Typography kept sleek, refined, slightly futuristic, and fully readable
- Subtle 3D depth on the text via soft glow/lighting, without sacrificing legibility
- No childish, cartoonish, overly colorful, or crowded elements

## Visual Concept
- Sophisticated 3D digital workspace/environment in the background
- Floating abstract elements representing:
  - Cloud computing (cloud node shape)
  - Software development (code brackets `</>`)
  - AI / networking (hexagon + globe/network node)
  - DevOps / infrastructure (server rack)
  - Data structures (isometric data cube)
- Elegant connecting lines linking the elements, suggesting a connected cloud/DevOps ecosystem
- Layered depth: a near layer (bold, glowing) and two fainter background layers for parallax-style depth
- Soft glow filters and drop shadows used instead of flat icons, for a realistic premium feel
- Visuals stay abstract and tasteful — no oversized logos plastered across the design

## Color Palette
| Role | Color |
|---|---|
| Background base | Deep black / charcoal (`#05070c` → `#0d1a2e`) |
| Secondary background | Dark navy blue |
| Accent (structure, nodes) | Electric blue (`#4fd8ff`, `#7fd8ff`) |
| Text | Silver / white gradient (`#ffffff` → `#a9c6e8`) |
| Ambient glow | Subtle cyan |

High contrast between text and background, but nothing neon or garish — kept elegant throughout.

## Composition Rules
- Left/center area kept clean and reserved for name + title
- 3D tech environment concentrated toward the right side and background
- Generous negative space — nothing crammed
- Wide horizontal format (1600×400 header, 1600×180 footer) built for a GitHub README banner
- Reads as personal branding first, technical decoration second

## Explicit Exclusions
The banner intentionally does **not** include:
- Email address
- Phone number
- Social media handles
- GitHub username as visible text
- Random usernames, watermarks, or placeholder text
- GitHub trophies
- Excessive emojis
- Gaming-banner or stock-photo aesthetics

## Footer Banner (companion piece)
- Same palette and node/line visual language as the header, at reduced height (180px)
- Centered tagline: *"Thanks for visiting — let's build something great"*
- Symmetric abstract elements (hexagon, server block, circle/ring nodes) balanced across the width
- Purpose: bookend the profile page so header and footer read as one cohesive visual identity

## Intended Impression
A serious, ambitious IT student building a career in software, cloud, and DevOps — polished enough for recruiters, internships, placements, and professional networking. A high-end personal technology brand rather than a generic developer README.
